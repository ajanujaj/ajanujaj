**AI Engineer** building production GenAI systems: RAG pipelines, multi-agent LLM workflows, and scalable inference services on AWS.

Currently at **Deloitte-USI**, where I own GenAI solutions end to end, from data ingestion and prompt versioning to deployment, evaluation and guardrails. - **LLMs in production**: FastAPI microservices on AWS ECS, Lambda and API Gateway, handling 500+ TPS

- **Deep learning and CV**: YOLOv5 object detection, CycleGAN style transfer, CNN + GCN medical imaging
